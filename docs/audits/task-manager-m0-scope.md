# M0 scope

M0 is inventory only. It does not change task behavior.

Included:

- identify the canonical task/project models;
- map current API and browser surfaces;
- classify existing evidence by strength;
- record missing or placeholder capabilities;
- identify false-positive verification caused by weak assertions;
- remove accidental public-facing internal comparison terminology found during the audit.

Excluded until later milestones:

- implementing missing task features;
- changing task lifecycle semantics;
- game feature development or game-readiness auditing;
- broad refactors not required to make the audit evidence truthful.

M1 begins only after this inventory is merged.
