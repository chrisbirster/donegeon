# A board with actual consequences

Donegeon is not just a task list with fantasy names. The board view changes how active work is managed.

## Core board mechanics

- Drag task stacks around a world surface
- Split or merge stacks as work changes shape
- Keep deck rows readable on desktop and mobile
- Use the minimap to navigate larger boards
- Track inventory and activation requirements before tasks go live

## Quest system

The quest runtime supports multiple quest types:

- Daily quests for regular operational discipline
- Story quests for longer arcs
- Seasonal quests for time-boxed pushes
- Boss quests for milestone work
- Failure quests when the board drifts out of control

Quest objectives can watch real work, including task completion, deck actions, villager assignment, backlog reduction, and zombie control.

## Rewards and pressure

The board runtime includes:

- Reward claims and collectible modifiers
- Villager stamina and progression
- Zombie pressure to keep backlog visible
- Collect, survival, and progression deck behavior

This matters on the marketing site because “gamified tasks” is too vague. Buyers need to see that the mechanics are grounded in real execution and not cosmetic points.
