# A board that changes behavior

Many tools say they combine task management with game mechanics. In practice, that often means points, badges, and a layer of presentation on top of the same basic workflow.

Donegeon goes further because the board actually changes how work is handled.

## The distinction that matters

The inbox is for capture.

The board is for active pressure.

Once work moves onto the board, the system can show:

- Activation requirements
- Inventory state
- Villager assignments
- Zombie pressure
- Quest objectives and rewards

That makes the board operational, not decorative.

## Why this matters for teams

Teams often need two things at the same time:

- Simple capture so nothing gets lost
- High-signal execution surfaces once the work matters

That is the tension Donegeon is built around. The updated marketing site now explains that more directly so the product does not get mistaken for a theme layer on top of a plain task app.
